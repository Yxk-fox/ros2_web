一、项目背景与定位

Mock Truck 管理工具是公司面向无人驾驶、矿区作业及物流运输场景的 ROS2 仿真车研发团队所使用的通用仿真测试平台。其核心价值在于：将原本散落在命令行、脚本与多台机器上的研发与运维操作，收敛为统一的 Web 界面，使研发、测试与运维人员能够通过浏览器完成容器调度、ROS2 调试、脚本批量执行、系统监控、故障注入、数据导出与安装目录多版本管理等工作。

工具采用前后端分离架构：后端基于 FastAPI 与 WebSocket，负责与 Docker、ROS2 及系统资源交互；前端为独立静态文件，提供图形化操作界面。当前版本为 v5.0，后端已实现四层解耦，并支持 install 安装目录多版本上传与切换，便于在不同软件版本间快速对比测试，便于维护与扩展。

一句话理解：这是一个把“ROS2 + Docker 的复杂命令行操作”变成“网页按钮”的内部工具，目的是让团队成员都能高效、规范地完成仿真与运维。

二、账号注册与登录

2.1 注册

  1. 打开系统登录页，切换到“注册”标签。
  2. 使用公司邮箱注册（用户名须为邮箱格式），密码不少于 6 位。
  3. 注册成功后，系统自动为该用户创建独立的工作目录，默认角色为 user，仅拥有首页权限。
注意：新注册用户默认无 Docker、脚本等权限，需联系管理员按需分配。

2.2 登录

  1. 在登录页输入邮箱与密码。
  2. 可勾选“记住我”并选择 7 / 15 / 30 天有效期；不勾选则默认 1 天。
  3. 登录成功后跳转至首页，左下角显示当前用户与登出按钮。

系统采用 JWT 鉴权，Token 过期后需重新登录。连续登录失败受速率限制保护（默认 5 次 / 分钟）。

四、权限模型

系统采用基于角色的权限控制（RBAC），并辅以细粒度权限点。

  • 角色：分为 admin（管理员）与 user（普通用户）两种。管理员可操作全部资源并管理用户；普通用户仅能操作自己创建的容器与脚本。
  • 权限点：如 docker（容器管理）、tools（系统工具）、advanced-docker（高级容器操作）等，由管理员分配。
  • 资源隔离：普通用户启动的容器仅自己可见；管理员可查看全部，并支持切换到目标用户空间代操作。
  • 审计：登录、容器操作、用户管理等关键行为均写入审计日志，管理员可查询。
注意：若发现某项功能不可见或按钮灰色，通常是权限不足，请联系管理员开通相应权限点。

五、典型工作流

5.1 工作流一：启动一辆仿真车

  1. 登录系统，确认拥有 docker 权限。
  2. 进入“Docker 管理”面板，点击 🔄 刷新 查看可用容器。
  3. 找到目标 ROS2 容器，点击 ▶ 启动（若已运行则跳过）。
  4. 点击该行的 ✅ 选中，将其设为当前操作目标。
  5. 进入“仿真控制”面板，在启动命令框输入 launch 命令，点击 ▶ 启动。
  6. 进入“节点管理”面板点击 🔄 刷新，确认关键节点已启动。
  7. 如需手动控车，在“速度控制”中使用摇杆或滑块。

5.2 工作流二：生成并批量执行脚本

  1. （如需切换软件版本）在首页「安装目录管理」卡片的版本下拉框中选择目标版本，点击 🔄 切换版本，确认后页面自动刷新，所有菜单随即在所选版本目录下工作。
  2. 进入“脚本管理”面板，点击 🔍 扫描 Launch 文件。
  3. 确认脚本生成参数无误，点击 ⚡ 生成 ROS2 脚本。
  4. 进入“仿真车启动”面板，勾选需要执行的脚本。
  5. 选择执行模式（顺序或并行），点击 ▶ 批量启动。
  6. 观察执行结果，失败可在“脚本执行增强”中开启自动重试。
注意：切换版本后，先前生成的启动脚本内路径仍是旧版本的，需重新生成脚本再执行；容器也需重启以挂载新版本，具体见《按钮操作手册》第十三章。

5.3 工作流三：监控与排障

  1. 进入“系统监控”面板，点击 ⏯ 自动刷新 持续观察资源占用。
  2. 若 CPU 或内存异常，展开“进程列表”定位高占用进程。
  3. 如需排查容器内问题，在 Docker 面板点击 📜 日志 或 💻 命令。
  4. 遇到无法解决的问题，可在“工单系统”提交工单并指派处理人。

七、常见误区与求助渠道

误区纠正
“为什么我看不到容器？”普通用户仅可见自己创建的容器；需先启动自己的容器或联系管理员。
“按钮点了没反应”检查是否已选中运行中的 ROS2 容器；查看浏览器控制台是否有报错。
“运行时长怎么不走了？”容器停止后运行时长自动归零，属正常；运行中每秒刷新。
“切换版本后行为没变”版本切换后需重新生成启动脚本并重启容器，新版本才会生效。
“误删了镜像 / 容器怎么办”容器与镜像删除不可恢复，操作前务必确认；如影响业务及时通知团队。

求助渠道：日常问题优先查阅《按钮操作手册》；技术细节参考《技术开发文档》；仍无法解决时提交工单或联系管理员。
