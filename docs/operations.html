摘　要

本手册面向一线操作与运维人员，逐一说明 ROS2 Web 管理工具各功能面板中按钮的含义、操作步骤、前置条件与注意事项。全文按功能模块组织，涵盖首页、仿真控制、话题与节点、Docker 容器管理、脚本生成与执行、镜像管理、系统监控、系统工具、红绿灯模拟、主题与设置、高级功能（容器增强、脚本重试、监控增强、工单、API 管理、分布式与插件、故障注入）等共二十一个面板。每节均给出操作流程与风险提示，旨在使操作者能够准确、安全地完成日常任务。

关键词：按钮操作；功能面板；操作流程；风险提示；故障排查

一、阅读说明与通用约定

系统采用左侧导航栏加主内容区的布局。导航项分为基础功能与高级功能两组，点击导航项切换面板；部分导航项带有二级子菜单，点击后展开。所有按钮均以图标加文字形式呈现，本手册中以 ▶ 启动 之类样式示意，颜色对应实际系统中的按钮配色。

表 1-1　按钮配色含义对照
配色含义典型按钮
绿色启动、确认、提交等正向操作启动、执行、保存
黄色停止、警告、需谨慎的操作停止、清空、移除参数
红色删除、注入等不可逆或高风险操作删除、停止全部、注入故障
棕色主要业务操作批量启动、可视化
白色辅助、查看、刷新类操作刷新、全部、关闭
注意：凡涉及删除、停止全部、注入故障等操作，系统可能弹出二次确认或直接执行，操作前请务必核对目标对象。
警告：权限不足时按钮会显示为禁用态（灰色、不可点击）。普通用户仅能操作自己创建的容器与脚本，管理员可操作全部资源。

二、首页与快速开始

首页为登录后默认页面，集中展示欢迎信息、安装目录状态与快速入口。其核心按钮如下。

2.1 安装目录管理

按钮作用操作说明
🔄 刷新重新检测 install 目录状态点击后后台扫描安装目录，更新目录是否存在、关键子目录是否齐全等状态展示。
🚀 部署到 bk 空间将当前 install 目录部署到备份（bk）空间仅管理员可见。点击后触发部署流程，用于版本归档与回滚。
📜 操作历史 / 回滚查看部署历史并回滚到历史版本仅管理员可见。弹出历史列表，可选择某次记录进行回滚。
警告：回滚操作会覆盖当前 install 目录内容，执行前请确认目标版本正确，必要时先手动备份。

2.2 快速开始

按钮作用操作说明
⚙ 配置配置快速开始项弹出配置面板，可设定常用启动命令、默认镜像等，配置后首页“快速开始”网格会生成对应快捷入口。

2.3 工作空间切换（管理员）

页面右上角的下拉框 workspaceUserSelect 仅管理员可见，用于切换到目标用户的工作空间进行操作（部署、同步等）。切换后，页面顶部会提示当前操作空间。

注意：管理员代操作用户空间时，所有写入行为都会记录到审计日志，请谨慎执行。

三、仿真控制面板

3.1 启动仿真

  1. 在 launchCmd 输入框中填写启动命令，例如 ros2 launch simulation_launches simulation.launch.py。
  2. 点击 ▶ 启动，系统在选中的容器内执行该命令。
  3. 观察右下角提示，成功后可在“节点管理”面板查看启动的节点。
警告：启动仿真前必须先在“Docker 容器管理”面板选中一个运行中的 ROS2 容器，否则命令无处执行。

3.2 速度控制（cmd_vel）

该模块通过摇杆与滑块两种方式向 /cmd_vel 话题发送速度指令，用于手动控制仿真车运动。

按钮作用操作说明
方向键 ▲▼◀▶发送对应方向速度按住发送、松开归零，默认线速度 0.5 m/s、角速度 0.5 rad/s。
⏹ 中心键立即停止发送零速指令，使车辆停止。
线速度 / 角速度滑块精细调节速度拖动滑块设定数值，点击 📤 发送速度指令 下发。

“话题”输入框可修改下发的话题名，默认为 /cmd_vel，支持自定义。

危险：实车调试场景下，发送非零速度前请确保车辆周围无人员与障碍物，并做好急停准备。

四、ROS2 话题 / 节点 / 服务 / Action

这四个面板结构相似，均提供“刷新加载—筛选—查看详情—调用”的操作链路。以下以话题面板为例说明，其余面板类同。

4.1 话题面板

按钮作用操作说明
🔄 刷新加载当前活跃话题列表从选中容器内执行 ros2 topic list 并展示。
筛选输入框按名称实时筛选输入关键字后列表即时过滤，无需点击按钮。
话题行“详情”查看话题类型与数据点击后展开话题详情卡片，可查看消息类型与一次回显。
收起 / 展开折叠面板点击右上角 ▼ 收起 折叠卡片。

4.2 节点 / 服务 / Action 面板差异

  • 节点面板：点击节点名查看节点信息（发布者、订阅者、参数等）。
  • 服务面板：选中服务后，在“调用”卡片中填写请求 JSON，点击 📞 调用 发起 ros2 service call。
  • Action 面板：填写目标值后点击 🎯 发送 发送 action goal，可观察反馈与结果。
注意：所有 ROS2 查询均依赖已选中运行中的 ROS2 容器，容器停止或未选中时相关按钮无效。

五、Docker 容器管理

该面板是日常运维的核心。容器列表展示名称、镜像、运行状态、运行时长、云平台连接与操作按钮。

5.1 顶部工具栏

按钮作用操作说明
🔄 刷新刷新 ROS2 容器列表默认仅显示 ros2_ 前缀的运行中容器。
📋 全部显示全部容器包括已停止的容器与非 ROS2 容器。
🔍 ROS2 容器仅显示 ROS2 容器按名称前缀与镜像特征过滤。
📦 其他容器显示非 ROS2 容器用于查看 grafana、prometheus 等辅助容器。
⏹ 停止全部 ROS2一键停止全部 ROS2 容器仅管理员可见。使用 docker kill 并行停止，请谨慎使用。
🕐 同步时间同步宿主机时间到容器仅管理员可见。用于修正容器内时间偏差。

5.2 容器行操作按钮

每行容器提供基础操作与“更多”展开操作两组按钮。

5.2.1 基础按钮

按钮状态作用
▶ 启动容器未运行时启动该容器。
⏹ 停止容器运行中停止该容器。停止后运行时长自动归零。
✅ 选中任意状态将该容器设为当前操作目标，ROS2 功能依赖此选中项。

5.2.2 更多操作（展开后）

按钮作用说明
📜 日志查看容器日志可在“Docker 日志”与“ROS2 日志”间切换。
💻 命令在容器内执行命令输入框支持常用命令补全，点击 ▶ 执行 运行。
⚙ 资源动态调整 CPU / 内存填写数值后点击 💾 应用，调用 docker update 即时生效。
🖥 终端打开普通终端ROS2 容器自动 source 环境。
👑 Root打开 Root 终端以 root 身份进入容器终端。
🖼 可视化启动可视化下拉菜单可选择 VNC 远程桌面或原生 RVIZ（X11 转发），仅 ROS2 运行中容器可见。
🗑 删除删除容器需有 Docker 权限，删除前请确认容器可弃。
注意：“运行时长”列以容器真实启动时间为准，每秒自动刷新。容器停止后该列显示“—”，无需手动清零。
警告：同一时刻仅允许展开一行的“更多”操作，展开新行时旧行自动收起。

六、脚本生成与仿真车启动

6.1 Launch 文件扫描

点击 🔍 扫描 Launch 文件，系统扫描选中容器的 launch 目录，列出可用的 launch 文件，供后续脚本生成使用。

6.2 生成启动脚本

该卡片展示脚本生成的各项路径与镜像参数（多数为只读，由系统配置自动填充）。

按钮作用
⚡ 生成 ROS2 脚本按配置生成一批启动脚本，写入脚本输出目录。
🗑 清空 Scripts清空已生成的脚本文件。
警告：“清空 Scripts”会删除脚本输出目录下的文件，请确认无误后再执行。

6.3 启动车辆（脚本批量执行）

按钮作用
筛选框按名称筛选脚本。
☑ 全选 / 🔄 反选 / ✕ 取消批量选择脚本。
执行模式下拉选择“顺序执行”或“并行执行”。
▶ 批量启动按所选模式批量启动选中的脚本。
🗑 移除 GPU 参数从选中脚本中移除 GPU 相关参数，用于无 GPU 环境调试。

七、镜像管理

按钮作用
🔄 刷新刷新本地镜像列表。
📁 打开弹出文件选择对话框，选择本地 tar 镜像文件。
📥 导入导入所选 tar 文件为 Docker 镜像，支持 .tar 与 .tgz。
镜像行“删除”删除本地镜像（docker rmi）。
警告：导入镜像前请确认文件来源可信，单个文件不超过 5 GB。删除镜像前请确认无容器依赖。

八、系统监控

按钮作用
🔄 刷新立即采集一次 CPU、内存、GPU、进程数据。
⏯ 自动刷新开关自动刷新，开启后按固定间隔循环采集。
🔄 刷新（资源泄漏）刷新资源泄漏监控数据。

监控页展示 CPU 整体与每核使用率、平均负载、内存与 Swap、GPU 利用率与显存、温度功耗，以及 Top 20 进程。GPU 信息依赖 nvidia-smi，未安装驱动时显示提示。

九、系统工具（install 配置）

9.1 证书与云环境切换

按钮作用
🔄 切换切换证书与云环境配置（测试 / 生产等），同步更新云 IP。
注意：普通用户若无 bk 证书目录，系统会自动从管理员空间拷贝，无需手动干预。

9.2 文件夹同步

点击 同步 mock_truck / simulation_launches 或 同步 control_launch，将宿主机对应目录同步到容器挂载路径，使代码修改即时生效。

9.3 bk 空间与车辆配置

按钮作用
🧹 清空子目录清空 bk 空间下选中子目录。
📂 从 install 复制将当前 install 内容复制到 bk 空间。
🔄 刷新列表刷新车辆配置列表。
💾 保存配置保存当前车辆配置。
🔄 重置重置为上次保存的配置。

9.4 Bag 与 Log 清理

按钮作用
清空 Bag清空录制的 bag 文件目录。
清空 Log清空日志目录。
打开 Bag / 打开 Log在文件管理器中打开对应目录。
危险：“清空 Bag / Log”不可恢复，执行前请确认无需保留的数据已转存。

十、红绿灯模拟

10.1 计时红绿灯

填写 SN、端口、目标 IP 与红绿黄灯秒数，点击 ▶ 启动 开始按计时循环切换；⏹ 停止 终止。

10.2 交通红绿灯（云端联动）

该模块通过 HTTP 登录与 MQTT 上报与云端交互。填写矿区 ID、服务器地址、登录与上报间隔等参数。

按钮作用
▶ 启动启动红绿灯模拟，自动登录并按间隔上报状态。
⏹ 停止停止模拟并断开连接。
切换为手动在自动与手动模式间切换。手动模式下可单选主灯 / 次灯颜色。
注意：若已手填 ID Token 并填写矿区 ID，系统跳过 HTTP 登录直接使用该 Token，便于调试。

十一、主题与系统设置

11.1 主题

提供深色、浅色、护眼三种预设主题，点击对应卡片即切换。

11.2 系统设置

包含软件源切换、软件包安装 / 卸载、用户与权限管理、审计日志查看等。其中“停止全部 ROS2”“同步时间”“软件源切换”等高风险操作仅管理员可见。

十二、高级功能面板

12.1 容器日志实时跟踪

选择容器后点击 ▶ 开始跟踪，实时输出日志；⏹ 停止 终止跟踪。

12.2 容器提交为镜像

选择容器、填写仓库名、标签与提交信息，点击 📦 提交为镜像，将当前容器状态固化为新镜像。

12.3 Foxglove Studio

选择容器后点击 🚀 打开 Foxglove，跳转到 Foxglove 可视化界面。

12.4 容器访问白名单

输入前缀（如 ros2_）点击 ➕ 添加，可限制容器访问范围。

12.5 失败自动重试

设置重试次数与间隔，点击 💾 保存设置；在脚本列表中选择脚本，点击 ▶ 批量执行（带重试）。

12.6 GPU 监控增强

点击 🔄 刷新 GPU 详情 或 ⏯ 自动刷新，查看 GPU 进程级占用（nvidia-smi pmon）。

12.7 工单管理

按钮作用
➕ 提交工单新建工单，填写标题、分类、优先级与描述。
🔄 刷新刷新工单列表。
状态 / 分类 / 优先级筛选按条件过滤工单。

12.8 REST API 管理

展示 API 服务状态与基础地址，可配置端口与 Token。按钮包括 💾 保存设置、🔍 测试连接、📖 查看 Swagger 文档、📄 查看 ReDoc 文档。

12.9 跨机器分布式管理

填写名称、主机、端口、用户，点击 ➕ 添加主机，可纳管多台远程机器。

12.10 插件管理

输入插件名与代码，点击 ➕ 创建 注册自定义插件；🔄 刷新 查看已有插件。

警告：插件执行默认关闭，启用前请审查插件代码，避免执行不可信代码。

12.11 故障注入

  1. 在“目标容器”中选择一个运行中的 ROS2 容器。
  2. 在“故障类型”网格中点击一种故障卡片（如 CPU 满载、内存泄漏、网络丢包等）。
  3. 在“参数配置”中填写参数（如持续时间、强度）。
  4. 点击 💥 注入故障 执行。
  5. 排查完成后点击 🧹 清除故障 恢复。
危险：故障注入会人为制造异常，仅用于鲁棒性测试。严禁在生产环境或实车运行中注入，否则可能导致任务失败或设备损伤。

十三、常见问题排查

表 13-1　常见问题与处理
现象可能原因处理方法
按钮灰色不可点击 权限不足或未选中容器 先在 Docker 面板选中运行中的 ROS2 容器；若仍不可用，联系管理员确认权限。
ROS2 话题列表为空 容器未运行 ROS2 程序 先在仿真控制面板启动 launch，再刷新话题。
运行时长显示“—” 容器已停止或启动时间未获取 属正常表现；启动容器后即显示时长，停止自动归零。
GPU 信息显示“无法获取” 未安装 NVIDIA 驱动或 nvidia-smi 确认宿主机已安装驱动；无 GPU 机器可忽略。
容器启动后云平台连接显示“未知” 容器未记录云 IP 标签 旧容器可能未设置 label，系统回退到当前配置 IP，可忽略或重建容器。
导入镜像失败 文件过大或格式不符 确认文件为 .tar 或 .tgz，且小于 5 GB。
批量执行脚本无响应 未选择脚本或镜像未拉取 确认已勾选脚本、目标镜像存在且容器已选中。
