摘　要

本中心为 Mock Truck 管理工具的统一文档入口，面向不同读者群体提供分层文档体系。工具定位为面向无人驾驶、矿区作业及物流运输场景的 ROS2 仿真车研发团队的通用仿真测试平台，以 Web 化方式封装 Docker 容器调度、ROS2 话题与节点管理、脚本批量执行、系统监控、故障注入、数据导出与安装目录多版本管理等核心能力，旨在降低一线操作门槛、统一操作规范、支撑远程协作与后续平台化扩展。当前版本 v5.0 已完成后端四层解耦与 install 多版本管理，全部文档按读者身份分为四类，风格统一，遵循论文式排版与中文标点规范。

关键词：ROS2；Docker 容器管理；仿真测试平台；Web 运维；install 多版本管理；降本增效；标准化合规

一、文档体系总览

文档体系依据读者职责与技术深度分为四类。各文档独立成篇，又彼此呼应：一线操作文档侧重“怎么点”，新入职手册侧重“怎么懂”，技术开发文档侧重“怎么改”，管理价值报告侧重“为什么建、带来什么”。读者可按身份选读，亦可交叉参考。

三、阅读约定

  • 文档统一采用论文式排版，章节以“一、二、三”与“1.1、1.2”分级编号。
  • 按钮示意以 ▶ 启动、⏹ 停止、🗑 删除 形式呈现，颜色与系统中保持一致。
  • 提示框分为 注意（绿色）、警告（黄色）、危险（红色）三级，分别对应一般提醒、易错点与可能导致数据丢失的操作。
  • 代码与命令以等宽字体呈现，路径、字段名等以 code 样式标识。
  • 本文档随系统迭代持续更新，如发现与实际界面不符，请以系统实际行为为准并反馈修订。
