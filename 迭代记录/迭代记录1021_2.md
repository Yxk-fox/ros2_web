## 任务 4：v1 与 v2 镜像差异对比

**结论：v2 是 v1 的“精简基础版”，v1 = v2 共同基础层 + 5 个容器 commit 层（共约 3.3GB）。v2 的文件系统是 v1 的严格子集（v2 无任何独有文件）。**

| 维度 | v1 | v2 |
|---|---|---|
| 磁盘占用 / 内容大小 | 19GB / 8.07GB | 14.8GB / 7.18GB |
| 默认 CMD | 自动启动整套可视化栈（Xvfb :41 + openbox + x11vnc + noVNC:6080 + `ros2 launch s_g00.py`） | `sleep 3600`（空转，由平台 exec 注入命令） |
| ENV | `DISPLAY=:41`、`ROS_DOMAIN_ID=41` | `DISPLAY=:0`、`ROS_DOMAIN_ID=63` |
| USER | root | boonray |
| 文件数 / 软件包 | 188631 / 1902 | 168260 / 1873 |

**v1 多出的内容（20371 个文件）：**
- `/home/boonray/world_sim`（312M，14467 个文件：ros2_ws 224M、lib 86M、run 2.6M）— 仿真世界数据
- `/root/.boonray/cfg`（229M）— 车辆配置 beve 文件
- `/usr` 多 2.4GB — ARM 嵌入式交叉编译工具链（arm-none-eabi 2.0G）、LLVM-14（222M）、cargo/Rust
- 31 个额外软件包：**openbox/obconf/wmctrl/scrot**（VNC 桌面窗口管理）、**gcc-arm-none-eabi 全家桶**、**llvm/libc++/libunwind-14**
- `/opt/ros` 171 个 `__pycache__` 运行时编译缓存、`/etc` openbox 配置、mesa 着色器缓存
- v2 仅有 2 个版本更旧的包：libuuid1/uuid-dev（3.4 vs v1 的 3.5）

**层历史：** v1 在共同基础层之上多了：`3.22GB`（运行过 Xvfb:8 可视化栈后 commit 的层，含 world_sim+工具链）、`56.9MB` + `0B`×2（sleep 3600 commit）、`31MB`（最终 Xvfb:41 CMD 层）。

两者 `/home/boonray/install` 均为空目录（ROS2 工作空间是运行时挂载的），Entrypoint/工作目录/暴露端口完全一致。

**验证方式**：修改前端后用 `node --check` 验证了 JS 语法，后端用 `ast.parse` 验证 Python 语法，均通过。刷新浏览器页面即可看到新界面。
